META 50K — aplicativo PWA

COMO USAR
1. Publique o conteúdo desta pasta em uma hospedagem HTTPS (por exemplo, GitHub Pages ou Netlify).
2. Abra o endereço publicado no Chrome do Android.
3. Toque em "Instalar Meta 50K no celular" ou no menu ⋮ > Instalar app / Adicionar à tela inicial.

RECURSOS
- Meta inicial de R$ 50.000 (editável).
- Rota padrão de R$ 130, limite de 2 rotas por data.
- Registro manual de gastos e outras entradas.
- Calendário e relatórios.
- Dados locais no navegador, com exportação/importação de backup.
- Cache offline após a primeira abertura online.

IMPORTANTE
Os dados ficam no armazenamento local do navegador/aparelho. Não há sincronização em nuvem. Exporte backups regularmente, principalmente antes de limpar os dados do navegador ou trocar de celular.
A instalação PWA exige hospedagem HTTPS (ou localhost para testes). Abrir o index.html diretamente como arquivo não habilita instalação nem service worker.
